This is a solution set for a lab assignment for Michael Brent's course, Algorithms 
for Computational Biology. 

In this assignment students implement the Expectation Maximization (EM) algorithm
for estimating parameters in a simple hidden-variable problem involving dice.

The assignment-specific files are in the `assignment` subdirectory. Specifically, 
the instructions are in `assignment/assignment.ipynb`.
